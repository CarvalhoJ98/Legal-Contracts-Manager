# 💼 Legal Contracts Manager

Olá! Este é o meu projeto de Gerenciamento de Contratos Jurídicos. Eu o desenvolvi para aprender na prática como funciona uma aplicação **Fullstack**, integrando o Frontend, o Backend e um Banco de Dados.

Aqui está uma demonstração do sistema em funcionamento:

![Demonstração do Sistema](./screenshot.webp)

## 🚀 Sobre o Projeto

Este sistema é um **CRUD** completo (Create, Read, Update, Delete). Ele permite cadastrar contratos, visualizar a lista em tempo real, editar informações existentes e excluir registros que não são mais necessários.

### 🛠️ Tecnologias Utilizadas

Para construir essa aplicação, usei as tecnologias mais modernas do mercado:

*   **Frontend:** [React](https://reactjs.org/) com Vite para uma interface rápida e reativa.
*   **Backend:** [Node.js](https://nodejs.org/) com [Express](https://expressjs.com/) para criar a nossa API.
*   **Banco de Dados:** [SQLite](https://www.sqlite.org/) para persistência de dados de forma simples e eficiente.
*   **Comunicação:** API REST com requisições JSON.

## 📖 O que eu aprendi?

Neste projeto, eu pude entender conceitos fundamentais como:

1.  **Estados no React:** Como o sistema "lembra" o que o usuário digita e atualiza a tela automaticamente.
2.  **Consumo de API:** Como fazer o navegador conversar com o servidor usando o comando `fetch`.
3.  **Criação de Servidor:** Como o Node.js recebe as informações e as processa.
4.  **Banco de Dados:** Como salvar, buscar, editar e deletar informações em um banco de dados real.

## ⚙️ Como rodar o projeto na sua máquina

Se você quiser testar esse projeto localmente, siga estes passos:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/CarvalhoJ98/Legal-Contracts-Manager.git
    ```
2.  **Instale as dependências:**
    Entre nas pastas `backend` e `frontend` e rode `npm install` em cada uma.
3.  **Inicie o sistema:**
    Você precisará de dois terminais abertos:
    *   No terminal 1 (Backend): `node server.js`
    *   No terminal 2 (Frontend): `npm run dev`
4.  **Acesse no navegador:**
    O Vite vai te fornecer um link (geralmente `http://localhost:5173`).
